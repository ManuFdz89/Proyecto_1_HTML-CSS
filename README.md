# Portfolio Personal - Manuel Fernández

Proyecto 1 de HTML y CSS realizado para la asignatura de Lenguaje de Marcas / Desarrollo Web.

## Descripción

Este proyecto consiste en una página web tipo portfolio personal, donde se presenta información sobre Manuel Fernández, sus intereses profesionales y una selección de proyectos académicos.

La web incluye una estructura completa con cabecera, navegación, sección principal, apartado sobre mí, galería de proyectos, formulario de contacto y pie de página.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Diseño responsive

## Funcionalidades

- Menú de navegación con enlaces internos.
- Sección hero de presentación.
- Apartado "Sobre mí".
- Galería de proyectos organizada con CSS Grid.
- Formulario de contacto básico.
- Diseño adaptable a distintos tamaños de pantalla mediante media queries.
